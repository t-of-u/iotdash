iotdash

ระบบปฏิบัติการขนาดเล็กสำหรับจอสัมผัส 7 นิ้ว (Waveshare ESP32-S3-Touch-LCD-7) ที่ให้เขียนแอปด้วย HTML, CSS และ JavaScript แล้ว compile เป็น image ไปรันบนบอร์ดโดยตรง ไม่มีเบราว์เซอร์อยู่ข้างใน

iotdash คืออะไร

iotdash ประกอบด้วยสามส่วนที่ทำงานร่วมกัน:

  • Firmware (C++) บน ESP32-S3: driver ของจอ RGB, touch, storage, ช่องสื่อสารกับคอมพิวเตอร์ (dev link) และ task ต่าง ๆ
  • Rendering engine lib/rt: ตัวแปล HTML/CSS เป็นภาพ (style, layout, paint) พร้อม JavaScript engine (QuickJS) ใช้ซอร์สชุดเดียวกันทั้งบนบอร์ดและใน simulator บน Mac
  • iotdash OS: ชั้นระบบปฏิบัติการบน engine มีหน้าจอ boot, home screen, แอปตั้งค่า, ระบบติดตั้งแอป, registry, หน่วยความจำของแอป, ไฟล์, background process, Wi-Fi/Bluetooth และแถบระบบด้านล่าง (home/back)

แอปเขียนเป็นเว็บธรรมดาในโฟลเดอร์ของตัวเองที่ไหนก็ได้ (iotdash create) เครื่องมือบนคอมพิวเตอร์ (tools/) จะเปิดแต่ละหน้าใน Chromium เพื่อวัดว่าใช้ฟอนต์ขนาดไหนบ้าง แล้ว render ฟอนต์ แปลงรูป และแพ็กทุกอย่างเป็นไฟล์ app.idb ไฟล์เดียว ก่อนส่งผ่าน USB ไปติดตั้งบนบอร์ด

คำสั่งที่ใช้บ่อย

รันจากโฟลเดอร์ iotdash/ ทุกคำสั่ง (รายละเอียดใน command line)

# firmware: build แล้ว flash ผ่าน USB (ช่อง UART)
~/.platformio/penv/bin/pio run -t upload

# OS: build ภาพระบบจาก os/core แล้วส่งลง storage ของบอร์ด
iotdash os deploy --build --to device

# แอป: build แล้วติดตั้ง / ถอนออก ผ่าน USB
iotdash create hello && cd hello
iotdash run                      # simulator
iotdash run --device             # บอร์ด
iotdash uninstall --to device

# ทดสอบบน Mac ด้วย simulator (ใช้การ์ดจำลองใน os/build/sdcard)
iotdash os sim

# ภาพหน้าจอจากบอร์ด, สถิติ, รัน JS บนบอร์ด
iotdash device shot
iotdash device stats
iotdash device eval "os.page()"

โครงสร้าง repository

โฟลเดอร์เนื้อหา
src/firmware เฉพาะบอร์ด: main.cpp (platform, task, dev link handler, fetch worker), radio.* (Wi-Fi + BLE), rgb_display.*, dma_blit.*, sdcard.*, imageslot.*, devlink.*, gt911.h, ch422g.h, board.h
lib/rt/rendering engine และ OS kernel (portable C++17): DOM, CSS, style, layout, render, raster, font, JS host, OS (os_net.cpp = policy ของ Wi-Fi/Bluetooth)
lib/quickjs/QuickJS-ng (JavaScript engine)
os/core/ซอร์สของระบบ: os.js (JS API), theme.css, shell/ (แถบระบบและ dialog), home/, boot/, apps/settings/, assets/, private/secrets.json (Wi-Fi ที่ติดมากับระบบ, ไม่อยู่ใน git)
bin/iotdashcommand line ของ SDK (ใส่ bin/ ใน PATH), scripts/setup.sh ติดตั้งครั้งแรก
templates/app/template ของ iotdash create
examples/แอปตัวอย่าง (calculator, dashboard, jstest): iotdash run calculator
store/app store ที่ host เองได้: backend/ (Lambda + DynamoDB + S3), frontend/ (React + Vite), scripts/deploy*.sh (คู่มือ)
web/engine + OS เป็น WebAssembly (web/build.sh) สำหรับ iotdash run --web และ simulator ของ iotstore
os/build/ผลการ build (ไม่เก็บใน git): boot.idb, card/, sdcard/ (การ์ดของ simulator), system-fonts.json
sim/simulator บน desktop (main.cpp, fake_radio.h, CMake)
tools/iotdash.py (CLI, compiler, dev link), project.py (คำสั่งของโปรเจกต์แอป), osbuild.py (build OS/แอป, card, Chromium reference), idbz.py, storeclient.py, requirements.txt
docs/เอกสารชุดนี้

README.md ที่ root ของ iotdash/ เขียนไว้ตั้งแต่ยังเป็น benchmark ของจอ (ก่อนมี engine และ OS) ข้อมูลหลายจุดในนั้นเก่าแล้ว ให้ถือเอกสารชุดนี้เป็นหลัก
