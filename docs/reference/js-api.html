JavaScript API ของ OS

API ที่ os/core/os.js เพิ่มให้ทุกหน้า (แอปและหน้าของระบบ) นอกเหนือจาก Web API มาตรฐาน function ที่ fail จะ throw Error พร้อมข้อความที่บอกสาเหตุ รายการ Web API มาตรฐานดูที่ Rendering engine

Navigation

APIคำอธิบาย

Background process

APIคำอธิบาย

process ที่ถูก watchdog หยุด (รันเกิน 3 วินาที) จะถูกปิดถาวร ดู JavaScript runtime

os

APIคำอธิบาย

os.store.cancel(id)หยุดการติดตั้งที่กำลังดาวน์โหลด (ไฟล์เดิมไม่ถูกแตะ)

ข้อต่างจาก browser ที่ควรรู้

  • Function.prototype.toString() ไม่คืน source ของฟังก์ชัน: ได้รูป function name() { [native code] } เสมอ เพราะ QuickJS ของ iotdash ไม่เก็บ source text (ประหยัดหน่วยความจำ ดู JavaScript runtime) โค้ดหรือ library ที่อ่าน source ของฟังก์ชัน (serialize ฟังก์ชัน, หาชื่อ parameter) จะใช้ไม่ได้ ส่วน new Function('…') และ eval ยังใช้ได้
  • Date ได้เวลาจริงหลัง Wi-Fi ต่อครั้งแรก (NTP, เขตเวลาไทย) ก่อนนั้นยังเป็นปี 1970 ข้อมูลที่ต้องประทับเวลาควรตรวจปีก่อน
  • fetch() รับ option timeout (ms, ค่าเริ่มต้น 15000) และคืนคำตอบ 4xx/5xx พร้อม body ตามปกติ (ดู fetch)

ตัวอย่างรวม

// main.js ของแอปที่ poll ข้อมูลและบันทึก log
const out = document.getElementById('out');
const last = localStorage.getItem('last');
if (last) out.textContent = last;

setBackgroundProcess('poll', 'APP', async () => {
  try {
    const r = await fetch('https://example.com/temp');
    const t = (await r.json()).value;
    localStorage.setItem('last', String(t));
    fs.appendFile('log.csv', `${Date.now()},${t}\n`);
    os.emit('temp', {t});
  } catch (e) {
    console.log('poll failed', e.message);
  }
  return 30000;
});

os.on('temp', ({t}) => { out.textContent = t; });
os.on('registry', ({key}) => { if (key === 'darkMode') document.body.dataset.theme = os.theme(); });

document.getElementById('clear').addEventListener('click', async () => {
  if (await os.confirm('Clear log', 'Delete every reading?', {ok: 'Delete'})) fs.remove('log.csv');
});
