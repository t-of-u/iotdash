อ้างอิง

เครื่องมือ command line

คำสั่งเดียว iotdash (bin/iotdash ของ SDK) ทำทุกอย่างฝั่งคอมพิวเตอร์: สร้างและ build แอป, simulator, ติดตั้งลงบอร์ดหรือการ์ด, แพ็กและส่งขึ้น store, ภาพระบบ, firmware และคุยกับบอร์ด เรียกจากที่ไหนก็ได้ (ใน script, CI, Makefile, npm scripts) คำสั่งของแอปทำงานกับโปรเจกต์ในโฟลเดอร์ปัจจุบัน

ติดตั้ง

cd iotdash && scripts/setup.sh          # ครั้งแรก (--web, --firmware: ส่วนเสริม) และใส่ bin/ ใน PATH ให้ (--no-path: ไม่ต้อง)
iotdash doctor                           # ตรวจเครื่องมือทั้งหมด
iotdash --version                        # OS ของ SDK และที่อยู่

bin/iotdash ตามลิงก์ไปหา SDK เอง (ลิงก์ไว้ใน /usr/local/bin ก็ได้) และสร้าง tools/.venv ให้ในครั้งแรก ต้องมี: Python 3.11+, CMake + compiler C++ (SDL2 สำหรับหน้าต่างของ simulator), PlatformIO สำหรับ firmware, Emscripten สำหรับ run --web

แอป

APP = โฟลเดอร์ของโปรเจกต์ (ค่าเริ่มต้น: โฟลเดอร์ปัจจุบัน หรือ parent ที่ใกล้ที่สุดที่มี app.json) หรือชื่อตัวอย่างใน examples/ ของ SDK เช่น calculator

คำสั่งทำอะไร
iotdash create DIR [--id ID] [--title T]โปรเจกต์ใหม่จาก templates/app (app.json, icon.svg, main.html/css/js, pages/about.html, README, .gitignore) id ค่าเริ่มต้นมาจากชื่อโฟลเดอร์
iotdash run [APP]build, ติดตั้งลงการ์ดของ simulator แล้วเปิดแอปในหน้าต่าง (--shot out.png: ถ่ายภาพแทนเปิดหน้าต่าง)
iotdash run [APP] --devicebuild, ติดตั้งผ่าน USB แล้วเปิดแอปบนบอร์ด (ใน connection เดียว เพราะการเปิด port ทำให้บอร์ด reset)
iotdash run [APP] --web [--port N] [--no-open]แอปในเบราว์เซอร์: pack แล้วเปิด web/dist/demo.html พร้อมแพ็กเกจ จาก HTTP server ในเครื่อง (Ctrl+C หยุด)
iotdash build [APP]compile → APP/build/app/ (app.idb, app.json, icon.img) ไม่ใส่ atlas ที่ระบบมีแล้ว
iotdash pack [APP] [-o FILE]build แล้วแพ็กเป็น IDBZ: APP/build/<id>-<version>.idbz (manifest ได้ os.min จาก app.json ค่าเริ่มต้น = OS ของ SDK)
iotdash install [APP] [--to T]build แล้วเขียน app.idb, icon.img, app.json, install.json ลง /applications/<id>/ (memory.json และ data/ เดิมยังอยู่)
iotdash install --pack FILE [--to T]ติดตั้งไฟล์ .idbz ตามที่ store จะติดตั้ง
iotdash uninstall [APP|ID] [--to T]ลบ /applications/<id> ทั้งโฟลเดอร์ (error ถ้าไม่ได้ติดตั้ง)
iotdash apps [--to T]รายชื่อแอปบน storage
iotdash publish [APP] [--pack FILE] [--store URL] [--email E] [--notes TEXT] [--draft]pack แล้วอัปโหลดขึ้น iotstore (สร้าง project ถ้ายังไม่มี) บัญชีจาก IOTSTORE_URL, IOTSTORE_EMAIL, IOTSTORE_PASSWORD (ถามถ้าไม่มี) ไม่บันทึกอะไรไว้ (tools/storeclient.py)
iotdash shot [APP] [--page P] [--dark]ภาพ simulator ข้างภาพ Chromium: APP/build/compare.png (และ shot-sim.png, shot-chromium.png)
iotdash doctorตรวจ Python tools, Chromium, ภาพระบบ, simulator, build เว็บ, PlatformIO, บอร์ดบน USB

ปลายทาง --to

ค่าหมายถึงคลาส
(ไม่ระบุ) หรือ simcard ของ simulator ที่ os/build/sdcardDirCard
deviceบอร์ดผ่าน USB (dev link, เขียนทีละ 4 KB แล้วรอ ACK เพราะ buffer รับของบอร์ดมี 6 KB)DeviceCard
path เช่น /Volumes/SDCARDการ์ดที่เสียบในคอมพิวเตอร์ (ไฟล์ ._* ของ macOS ถูกลบให้)DirCard

เมื่อเขียนเสร็จ DeviceCard.done() ส่ง APPS_CHANGED (ติดตั้ง/ลบแอป) หรือ OS_RELOAD (deploy ระบบ) ให้บอร์ดอัปเดตทันทีโดยไม่ต้อง reset

OS: iotdash os …

คำสั่งทำอะไร
iotdash os buildbuild system image (os/build/card/system/os.idb + os.json + default icon), boot image (os/build/boot.idb ฝังใน firmware) และ os/build/system-fonts.json ถ้ามี os/core/private/secrets.json จะติดไปใน system image ด้วย (Wi-Fi ที่ติดมากับระบบ)
iotdash os deploy [--to T] [--build]เขียน /system ลง storage (build ก่อนถ้ายังไม่มี หรือเมื่อมี --build) แล้วสั่ง reload
iotdash os format [--to T]format storage (ลบทุกอย่างรวมระบบ) แล้วสร้าง /system/data, /applications ต้อง deploy ใหม่หลังจากนี้ ต่างจาก Format ใน Settings ที่เขียนระบบกลับให้
iotdash os sim [--script S] [--shot out.png]boot OS ใน simulator จาก card ของ sim (build/deploy ให้ถ้ายังไม่มี)
iotdash os ref [--page P] [--app DIR] [--js CODE] [--dark] [-o out.png]ภาพที่ Chromium วาดหน้าเดียวกัน (800×480, font เดียวกัน, stub ของ os) ไว้เทียบกับบอร์ด --page ค่าเริ่มต้น system/apps/settings/main.html; หน้าของแอปใช้ --app DIR --page app/main.html (หรือ iotdash shot)
iotdash os ref --js "showTab('sdcard')" -o ref.png
iotdash os ref --app examples/calculator --page app/pages/history/main.html --dark -o hist.png

บอร์ด: iotdash device …

ทุกคำสั่งเปิดพอร์ต (บอร์ด reset), รอ PING แล้วทำงาน (ยกเว้น log)

คำสั่งทำอะไร
iotdash device shot [out.png]ภาพหน้าจอ (page ล่าสุดที่ present) ค่าเริ่มต้น device.png
iotdash device statsบรรทัด stats (ดู การวัดผล)
iotdash device eval "JS"รัน JS ในหน้าปัจจุบันและพิมพ์ผล
iotdash device open IDเปิดแอปตาม id
iotdash device wifi "SSID:PASS"ต่อ Wi-Fi ทันทีแบบเดียวกับ Settings: บันทึกลง registry (secure.wifi) เมื่อต่อได้ แล้วต่อเองทุกครั้งที่ boot ตอบ "connecting (saved once it is up)"
iotdash device resetesp_restart()
iotdash device tap X,Yแตะจำลอง (DOWN แล้ว UP ห่าง 80 ms) ผ่านคิวเดียวกับนิ้วจริง
iotdash device log [วินาที]พิมพ์ log ของบอร์ด (ค่าเริ่มต้น 5 วินาที) ไม่รอ PING จึงเห็น log ตั้งแต่ boot
iotdash device probe [cs0|cs1] [sck0|sck1|sckz] [mosi…] [miso…]ตั้งสถานะสาย SD (ถ้าระบุ) แล้ว stream แรงดันที่ GPIO6 จนกด Ctrl-C (คืนสายเป็นปกติให้ตอนออก)
-vแสดง log ของบอร์ดระหว่างคำสั่งอื่นด้วย

คำสั่ง text อื่นๆ (เช่น ilog, Tarm, F) ส่งเป็นบรรทัดข้อความธรรมดาทาง serial ได้ เช่นด้วย pio device monitor หรือ Python ดูรายการเต็มใน Dev link

App store: iotdash store …

คำสั่งทำอะไร
iotdash store dev [--api | --web]API (store/backend/run_local.sh, :9310) และเว็บ (Vite, :5310) ในเครื่อง ต้องมี store/backend/.env.local (ติดตั้ง node_modules ให้ครั้งแรก)
iotdash store testtest ของ API (pytest, สร้าง backend/.venv ให้ถ้ายังไม่มี)
iotdash store deploy [--dry-run] [--config FILE]store ของคุณบน AWS จาก store/deploy.env (store/scripts/deploy.sh)
iotdash store deploy-web [--config FILE]build เว็บสำหรับ store นั้น (store/scripts/deploy-web.sh)

รายละเอียดใน App store

Firmware: iotdash firmware

iotdash os build                 # ต้องมี os/build/boot.idb ก่อน (ฝังใน firmware)
iotdash firmware                 # build (PlatformIO ในโฟลเดอร์ SDK)
iotdash firmware upload          # build + flash (ไม่ลบ fs/sys/slots/registry)
iotdash firmware monitor         # 921600 baud

เพิ่ม page buffer เป็น 3 ได้ด้วย build_flags = … -DRGB_PAGES=3 ใน platformio.ini (ดู การแสดงผล)

คำสั่งยุคก่อน OS (แอปเดี่ยว)

ก่อนมี OS บอร์ดรันแอปเดียวจาก partition bundle คำสั่งชุดนี้อยู่ใต้ iotdash legacy …:

คำสั่งสถานะ
iotdash legacy build APP [-o out] [--ref]ใช้ได้: compile โฟลเดอร์ใดก็ได้เป็น IDB1 (APP/build/bundle.bin), --ref เก็บภาพ Chromium ไว้ด้วย
iotdash legacy sim APP [--shot] [--script] [--page]ใช้ได้: เปิด bundle เดี่ยวใน simulator (ไม่มี OS)
iotdash legacy shot APP [--page] [--script]ใช้ได้: ภาพ sim เทียบกับ Chromium ข้างกัน (APP/build/compare.png)
iotdash legacy dev APP [--commit]ใช้ไม่ได้กับ firmware ปัจจุบัน: บอร์ดตอบ FILE/BUNDLE/COMMIT ว่า "single bundles are gone"
iotdash legacy flash APP [--fw]ห้ามใช้: เขียน bundle ที่ offset 0x400000 ซึ่งตอนนี้คือ partition sys (ทับ system image ใน flash; แก้ได้ด้วย reboot ให้คัดลอกจาก storage ใหม่)
