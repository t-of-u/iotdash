App store (iotstore)

store ที่มากับ SDK อยู่ใน store/: นักพัฒนาอัปโหลดแพ็กเกจของแอปและเก็บทุกเวอร์ชัน ลองแต่ละเวอร์ชันบนบอร์ดจำลองในเบราว์เซอร์ ส่วนบอร์ดติดตั้ง อัปเดต และลบแอปจากแอป Apps ใครก็ deploy store ของตัวเองลง AWS ได้ แอปใน store เป็นของผู้ที่ publish

ส่วนประกอบ

ส่วนอยู่ที่
APIstore/backend/AWS Lambda (Python 3.13) + DynamoDB (key pk + sk) + S3 รายละเอียดใน store/backend/README.md และ store/docs/API.md
เว็บstore/frontend/React + Vite + TypeScript: project, เวอร์ชัน (อัปโหลด, notes, publish, ดาวน์โหลด, ลบ) และหน้า Simulate ที่รัน OS จริงเป็น WebAssembly (web/) พร้อม Wi-Fi, Bluetooth และเกมตาชั่งจำลอง
Deploystore/deploy.env, store/scripts/สร้างหรืออัปเดตทุก resource บน AWS จาก config ไฟล์เดียว
บนบอร์ดos/core/apps/store/, lib/rt/os_store.cppแอป Apps และการติดตั้งแบบ stream ลงการ์ด (รายละเอียด)
CLItools/storeclient.pyiotdash publish
  • อัปโหลด: API ให้ presigned POST ของ S3 เบราว์เซอร์ (หรือ iotdash publish) ส่งไฟล์ตรงเข้า S3 แล้ว API ตรวจแพ็กเกจ (checksum, app id ตรงกับ project, เวอร์ชันใหม่)
  • ติดตั้ง: บอร์ดขอ API ได้ presigned GET ของ S3 แล้วโหลดแพ็กเกจจาก S3 เอง
  • บอร์ดเห็นเวอร์ชันล่าสุดที่ publish แล้วและ os.min ไม่ใหม่กว่า OS ของบอร์ด

รันในเครื่อง

cp store/backend/.env.example store/backend/.env.local   # ครั้งแรก: JWT_SECRET_KEY, STORAGE (s3 + AWS_PROFILE หรือ local)
iotdash store dev          # API :9310 + เว็บ :5310 (--api / --web: อย่างเดียว) Ctrl+C หยุดทั้งคู่
iotdash store test         # test ของ API

บอร์ดในวงเดียวกัน: แอป Apps → Store address → http://<IP ของเครื่อง>:9310 บัญชีแรกที่สมัครเป็น admin ของ store

Deploy store ของตัวเอง

cp store/deploy.env.example store/deploy.env   # STORE_NAME, AWS_PROFILE, AWS_REGION, WEB_ORIGIN, SIGNUP …
iotdash store deploy --dry-run   # ดูว่าจะสร้าง/แก้อะไร (อ่านอย่างเดียว)
iotdash store deploy             # table, bucket + CORS, role, layer, Lambda, function URL: พิมพ์ URL ของ API
iotdash store deploy-web         # build เว็บ (และอัปโหลดขึ้น S3 ถ้าตั้ง WEB_BUCKET)
สร้างชื่อ (ตั้งเองใน deploy.env ได้ ทุกรอบจะพิมพ์ชื่อที่ใช้)
DynamoDB<TABLE_PREFIX>users, -projects, -versions (prefix เริ่มต้น <STORE_NAME>-)
S3S3_BUCKET_NAME หรือ <STORE_NAME>-packages-<account id> (private, CORS ตาม WEB_ORIGIN)
LambdaFUNCTION_NAME (เริ่มต้น <STORE_NAME>-api) + layer <function>-deps + function URL
IAM<function>-role
  • รันซ้ำได้: ที่ยังไม่มีจะถูกสร้าง ที่มีแล้วจะถูกอัปเดต (โค้ด, ค่าตั้ง, CORS) โดยเก็บ JWT key เดิม
  • หลาย store ในบัญชีเดียว: config คนละไฟล์ที่ STORE_NAME ต่างกัน iotdash store deploy --config staging.env
  • เว็บ: ตั้ง WEB_BUCKET แล้ว deploy-web ทำ bucket นั้นเป็น S3 website ให้ครบ (เปิด hosting, ทุก path ไป index.html, policy อ่านได้แบบ public, ปิด ACL, สร้าง bucket ถ้ายังไม่มี) อัปโหลดแล้วพิมพ์ URL ส่วน deploy ใส่ URL นั้นใน CORS ให้เอง ถ้าจะใช้ HTTPS หรือโดเมนของตัวเองให้ใส่ CloudFront ข้างหน้า หรือ WEB_HOSTING=private แล้ว host เอง (path ที่ไม่มีกลับไป index.html, .wasm เป็น application/wasm)
  • SIGNUP=closed: สมัครได้เฉพาะบัญชีแรก (admin)

ส่งแอปขึ้น store

cd my-app
iotdash pack                     # build/my-app-1.0.idbz: อัปโหลดในหน้า project ของเว็บ หรือ
IOTSTORE_URL=https://<API> IOTSTORE_EMAIL=me@example.com iotdash publish --notes "อะไรเปลี่ยน"
