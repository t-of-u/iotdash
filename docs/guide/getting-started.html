เริ่มต้น

ติดตั้งและใช้งานครั้งแรก

iotdash เป็น SDK แบบเดียวกับ Flutter: ติดตั้งครั้งเดียว ใส่ bin/ ไว้ใน PATH แล้วสร้างแอปเป็นโปรเจกต์ที่ไหนก็ได้ หน้านี้ไล่ตั้งแต่เตรียมเครื่อง, firmware, วางระบบลงบอร์ด, แอปแรก จนถึงวิธีทำงานประจำวัน

สิ่งที่ต้องมี

สิ่งที่ต้องมีใช้ทำอะไรหมายเหตุ
PlatformIO (pioarduino)build และ flash firmwareเรียกผ่าน ~/.platformio/penv/bin/pio ใช้ Arduino core 3.x บน ESP-IDF 5.5 (compile framework ใหม่ตาม custom_sdkconfig)
Python venv tools/.venvcompiler ของแอป/OS, dev link, เครื่องมือทั้งหมดต้องมี freetype-py, uharfbuzz, pillow, numpy, playwright, pyserial, fonttools (ดู tools/requirements.txt)
Chromium ของ Playwrightวัดว่าหน้าเว็บใช้ฟอนต์ขนาด/น้ำหนักไหน, ตัดคำภาษาไทย, render icon, ภาพอ้างอิงติดตั้งด้วย tools/.venv/bin/playwright install chromium
CMake + zlib (SDL2 ไม่บังคับ)build simulatorไม่มี SDL2 ก็ใช้แบบ headless (--shot, --script) ได้
# ครั้งแรก: เครื่องมือ Python + Chromium, ภาพระบบ, simulator แล้วตรวจทั้งหมด
cd iotdash
scripts/setup.sh                 # --web: build สำหรับเบราว์เซอร์ด้วย, --firmware: firmware ด้วย
echo 'export PATH="$PATH:'$PWD'/bin"' >> ~/.zshrc   # แล้วเปิด terminal ใหม่
iotdash doctor                   # ✓ ครบ = พร้อม

bin/iotdash ใช้ Python ใน tools/.venv ของ SDK เสมอ (สร้างให้เองครั้งแรก) จึงไม่ต้องสนใจ Python ของระบบหรือของ PlatformIO iotdash --version บอกว่า SDK อยู่ที่ไหน

ต่อสายบอร์ด

  1. ใช้ช่อง USB-C ที่พิมพ์ว่า UART ชิป CH343 จะขึ้นเป็น /dev/cu.usbmodem5B901262921 ชื่อนี้ตั้งไว้ใน platformio.ini (upload_port) และ tools/iotdash.py (PORT) ถ้าเครื่องคุณขึ้นชื่ออื่นให้แก้สองที่นี้
  2. สวิตช์ UART_SEL (SW1) บนบอร์ดต้องอยู่ฝั่ง USB/UART ถ้าเลื่อนไปฝั่ง header UART ภายนอก ช่อง USB จะต่อกับ ESP ไม่ได้
  3. ความเร็ว serial คือ 921600 baud ทั้ง flash และ dev link

การเปิด serial port จะ reset บอร์ด (สาย DTR/RTS ต่อกับ EN/IO0) ทุกคำสั่งของ iotdash ที่คุยกับบอร์ดจะรอให้บอร์ดตอบ PING ก่อนทำงาน ถ้าจะทดสอบหลายขั้นตอนต่อเนื่อง ให้เขียนเป็นสคริปต์ที่เปิด Link ครั้งเดียว ดู การ debug

Build และ flash firmware

firmware ฝังภาพหน้าจอ boot (os/build/boot.idb) ไว้ข้างใน (board_build.embed_files) จึงต้อง build OS อย่างน้อยหนึ่งครั้งก่อน build firmware ครั้งแรก

iotdash os build                 # สร้าง os/build/boot.idb และภาพระบบ
iotdash firmware upload          # build + flash (PlatformIO)
  • build ครั้งแรกใช้เวลาหลายนาที: pioarduino compile Arduino core และ ESP-IDF ใหม่ตาม custom_sdkconfig ราว 6 นาที รอบต่อ ๆ ไปประมาณ 1 นาที
  • ถ้าแก้ custom_sdkconfig: framework จะถูก build ใหม่ทั้งหมด ส่วนการปิดค่าที่ Arduino เปิดไว้เป็นค่าเริ่มต้น ต้องเขียนในเครื่องหมายคำพูด เช่น '# CONFIG_LCD_RGB_RESTART_IN_VSYNC is not set' ไม่อย่างนั้น ini จะถือเป็น comment
  • ถ้า upload ขึ้น Failed to connect ... No serial data received: กด BOOT ค้าง กด RESET หนึ่งครั้ง ปล่อย BOOT แล้ว upload ใหม่ ถ้าขึ้น port is busy แปลว่ามีโปรแกรมอื่นเปิด port อยู่ เช่นคำสั่ง device log หรือ pio device monitor
  • การ flash firmware ไม่ลบข้อมูล: pio เขียนแค่ bootloader, partition table และ app ส่วน file system (fs), ภาพระบบใน sys/slots และ registry ยังอยู่

ใส่ Wi-Fi ให้ระบบ (ก่อน build OS)

ถ้าอยากให้บอร์ดต่อ Wi-Fi ได้เองตั้งแต่ boot แรก ให้สร้างไฟล์ os/core/private/secrets.json ก่อน build ภาพระบบ ไฟล์นี้อยู่ใน .gitignore จึงไม่ถูก commit

mkdir -p os/core/private
cat > os/core/private/secrets.json <<'EOF'
{"wifi": [{"ssid": "MyOffice", "pass": "office-password"}]}
EOF
  • os build / os deploy --build ใส่ไฟล์ไว้ใน system image (หน้าเว็บและแอปอ่านไม่ได้) เมื่อระบบเริ่ม OS รวมเครือข่ายเหล่านี้เข้ากับที่บันทึกไว้ (เฉพาะเมื่อไฟล์เปลี่ยน) เปิด Wi-Fi แล้วต่อเครือข่ายที่อยู่ในระยะเอง
  • ใส่ได้หลายเครือข่าย ตัวแรกได้ลำดับก่อน แก้ไฟล์แล้ว deploy ใหม่ (os deploy --build) เพื่อเปลี่ยน
  • ไม่ใส่ไฟล์ก็ได้: เลือกเครือข่ายบนจอที่ Settings → Connection → Wi-Fi หรือสั่งจากคอมพิวเตอร์ iotdash device wifi "SSID:PASS"
  • บอร์ดได้เวลาจริงจาก NTP หลังต่อครั้งแรก รายละเอียดอยู่ที่ Wi-Fi และ Bluetooth

วางระบบ (OS) ลง storage

เปิดบอร์ดครั้งแรกจะเห็นหน้าจอ boot ตามสถานะของ storage:

ข้อความบนจอ bootความหมายทำอย่างไร
Insert an SD cardไม่มี SD และไม่มี flash file system (กรณีปกติจะไม่เจอแล้ว เพราะบอร์ดสลับไปใช้ flash เอง)ใส่การ์ด หรือตรวจ partition fs
The SD card has no file systemอ่านการ์ดได้แต่ไม่มี FATกดปุ่ม Format บนจอ หรือ os format --to device
The system is not installed on this cardstorage ไม่มี /system/os.jsonos deploy --to device
Loading the systemกำลังคัดลอกภาพระบบลง flash slot (เฉพาะตอนภาพเปลี่ยน)รอ แถบความคืบหน้าจะวิ่ง
The system image is damagedอ่าน /system/os.idb ไม่ได้หรือ format ผิดdeploy ใหม่
# build ภาพระบบจาก os/core แล้วส่งลงบอร์ด (ประมาณ 22 วินาทีสำหรับ 1.7 MB)
iotdash os deploy --build --to device

หลังส่งเสร็จ เครื่องมือจะสั่ง OS_RELOAD บอร์ดจะ boot ระบบใหม่ คัดลอกภาพลง flash slot แล้วเข้าหน้า home ซึ่งจะมีแอป Settings ติดมากับระบบ ถ้ามี secrets.json บอร์ดจะต่อ Wi-Fi นั้นภายในไม่กี่วินาที (ดูได้ที่ Settings → Connection)

แอปแรก

แอปคือโฟลเดอร์ที่ไหนก็ได้ (app.json + main.html + ไฟล์อื่นที่หน้าใช้) คำสั่งทำงานกับโฟลเดอร์ปัจจุบัน

cd ~/projects
iotdash create hello-board       # โปรเจกต์ใหม่จาก template (app.json, icon.svg, main.html/css/js, README)
cd hello-board
iotdash run                      # build, ลงการ์ดของ simulator แล้วเปิดแอปในหน้าต่าง
iotdash run --device             # ลงบอร์ดผ่าน USB แล้วเปิดแอป
iotdash run --web                # ในเบราว์เซอร์ (WebAssembly, ต้องมี web/dist: scripts/setup.sh --web)
iotdash shot                     # simulator เทียบกับ Chromium: build/compare.png
iotdash pack                     # build/hello-board-1.0.idbz สำหรับ store
iotdash uninstall --to device    # ลบแอปพร้อม data/ และ memory.json

แอปที่ติดตั้งจะขึ้น icon ที่หน้า home ทันทีโดยไม่ต้อง reboot (เครื่องมือส่ง APPS_CHANGED) ถ้าแอปนั้นเปิดค้างอยู่ระหว่างติดตั้งใหม่หรือถอนออก ระบบจะปิดแอปแล้วกลับหน้า home ตัวอย่างที่มากับ SDK ใช้ชื่อแทนโฟลเดอร์ได้: iotdash run calculator (examples/)

ใช้ simulator

simulator คือ engine และ OS ชุดเดียวกับบนบอร์ด build สำหรับ Mac ใช้การ์ดจำลองที่โฟลเดอร์ os/build/sdcard ของ SDK (ทุกโปรเจกต์ใช้การ์ดนี้ร่วมกัน เหมือน emulator ตัวเดียว)

iotdash run                                    # แอปของโฟลเดอร์นี้
iotdash os sim                                 # เปิด OS เฉย ๆ (หน้าต่างถ้ามี SDL2)
iotdash os sim --script "wait 1500; launch calculator; wait 800; shot /tmp/c.png"
iotdash apps                                   # แอปบนการ์ดของ simulator (--to device: บนบอร์ด)

คำสั่งใน script และตัวเลือกตรวจสอบต่าง ๆ อยู่ในหน้า Simulator

วิธีทำงานประจำวัน

แก้อะไรทำอะไรต่อ
แอป (โฟลเดอร์ของแอป ที่ไหนก็ได้)iotdash run หรือ iotdash run --device (ข้อมูล data/ และ memory.json ของแอปยังอยู่)
ระบบใน os/core (home, settings, shell, theme, os.js)iotdash os deploy --build --to device
หน้าจอ boot (os/core/boot)os build แล้ว flash firmware ใหม่ เพราะ boot image ฝังอยู่ใน firmware
engine (lib/rt) หรือ firmware (src/)iotdash firmware upload แล้วทดสอบใน simulator ด้วย (โค้ดชุดเดียวกัน)
ต้องการเช็กว่าหน้าเว็บวาดถูกตาม HTML ไหมiotdash shot (แอป) หรือ iotdash os ref --page ... -o ref.png (ระบบ) แล้วเทียบกับ iotdash device shot

ปัญหาที่พบบ่อย

  • board did not answer: บอร์ดไม่ตอบ PING ภายใน 12 วินาที ตรวจสาย, port และสวิตช์ UART_SEL
  • ภาพบนจอกระตุกหรือแตก: ดูตัวเลข tears ในคำสั่ง device stats ต้องเป็น 0 ถ้าไม่ใช่ ดูวิธีไล่ใน การ debug
  • แอปกดแล้วตอบช้า: ดูเวลา style/layout/paint และจำนวน element ที่ถูกคำนวณ style ใหม่ใน stats และอ่านข้อแนะนำใน การเขียนแอป
  • หน่วยความจำ: stats บอก psram ที่เหลือ ควรเหลือมากกว่า ~300 KB ตลอดเวลา
  • ต่อ Wi-Fi ไม่ได้: Settings → Connection บอกสาเหตุ (wrong password, network not found, timed out) บอร์ดใช้ได้เฉพาะ 2.4 GHz; "Connected, no internet" = ต่อ router ได้แต่ตรวจ generate_204 ไม่ผ่าน
  • Wi-Fi หรือ Bluetooth ไม่ยอมเปิด ("not enough memory"): SRAM ภายในไม่พอ ดูด้วยคำสั่ง text heap (รายละเอียด)
